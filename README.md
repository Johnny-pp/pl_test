# 幻兽远征

一款基于 Phaser 4、TypeScript 和 Vite 的原创网页幻兽养成游戏。目前已打通探索、遭遇、回合战斗、捕获、队伍、基地生产和配种孵化的完整试玩循环。

项目只参考同类游戏和资料站的数据维度，不直接搬运名称、描述或数值。当前 36 个物种、17 个主动技能、26 个被动技能、5 种探索能力与头像图集均为项目原创内容。

## 功能

- 图鉴搜索、排序、分页、详情、被动技能筛选与双幻兽对比
- 元素克制、能量、先手、状态效果、六只队伍换宠和捕获判定的回合战斗
- 三地区瓦片地图探索、障碍碰撞、昼夜/区域遭遇、资源采集和在线自动巡逻挂机
- 可由战斗、捕获和基地资源解锁的云脊高地，以及独立地图、采集物与昼夜生态
- 阶段十五实施中的第三地区“星潮群岛”，包含安全聚落、湿地、遗迹、独立渡门和探索进度存档基础
- 串联战斗、捕获、探索和制造的任务链，以及具备状态抗性和半血强化阶段的区域首领
- 统一生效于战斗和基地的被动规则、叠加上限与配种继承收益
- 六只队伍编组、治疗道具、版本化本地存档与备份导入导出
- 50 级成长、三种经验曲线、战斗经验结算、连续升级与成长属性实装
- 岗位适性、离线生产、仓库、设施升级和道具制造
- 后代预览、被动继承、蛋品质、倒计时和孵化队列
- 个体构筑：物种技能树、技能点解锁、4 主动技能配置与核心/护符/护甲三槽装备
- 芦灯港聚落：原创 NPC 对话、商店（星币买卖与限量库存）、队伍治疗与支线引导
- 星币与掉落物经济：战斗掉落、制造品与探索奖励可出售，兑换商店用品和装备
- 6 条不同目标类型的支线任务，任务页支持主线/支线切换
- 砍藤/碎岩/涉水/滑翔/照明 5 种探索能力，用于开启星潮群岛机关门、隐藏宝箱与瞭望点
- 可见精英训练者挑战：固定身份、明确奖励与可配置重战规则
- 基地经营：6×4 格子布局、设施占地/邻接加成、科技树、矿石→金属→装备/高级捕获器加工链与可重复基地订单
- 响应式画面、移动端触屏方向键、键盘焦点、场景状态播报和场景按需加载

## 本地开发

需要 Node.js 24（CI 使用的版本）和 npm。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://localhost:5173`。Vite 已监听局域网地址，同一网络中的设备可访问终端显示的 `Network` 地址；请确认操作系统防火墙允许对应端口。开发检查时可访问 `/?start=world` 直接进入探索地图。

## 操作

- 地图移动：方向键或 `W/A/S/D`
- 采集交互：靠近资源后按 `E`
- 探索挂机：点击地图右上角“开始挂机”，角色会自动巡逻、采集并完成普通战斗；手动移动、离开探索或切到后台会暂停
- 自动捕获：挂机胜利后只对尚未拥有的物种消耗一个捕获器尝试捕获；传送门和区域首领始终需要手动操作
- 移动设备：使用画面内方向键和交互按钮
- 其他界面：鼠标点击或触屏点击；长列表可滚轮滚动

## 质量检查与构建

```bash
npm run check
```

统一命令会依次检查格式、ESLint、TypeScript 类型、单元测试、JSON Schema/跨表引用，并生成生产构建。也可以单独执行：

```bash
npm run format
npm run lint
npm run typecheck
npm test
npm run validate
npm run build
```

安装 Firefox 与 Geckodriver 后，还可运行真实浏览器关键流程验收：

```bash
npm run test:browser
```

该流程覆盖任务领奖、基地制造、探索挂机、自动战斗与新品种捕获、键盘打断、屏幕方向键、移动端画布、战斗升级、刷新后的存档恢复、个体构筑（技能树解锁与装备穿戴）、商店买卖、探索机关门、精英挑战、支线领取、基地布局/科技/加工链/订单和基础无障碍状态。

生产文件输出到 `dist/`。由于构建使用相对资源路径，可以用任意静态文件服务托管该目录，例如：

```bash
npx serve dist -l 4173
```

部署到局域网时，让静态服务监听 `0.0.0.0`，再通过主机局域网 IP 和端口访问。仓库中的 GitHub Actions 会在 push 和 pull request 时运行 `npm ci` 与 `npm run check`。

## 存档

进度保存在浏览器 `localStorage`，当前存档版本为 v10，并会自动迁移旧版等级、经验、生命值、区域、任务、首领、世界探索进度、个体构筑（技能树节点、装备技能与装备槽）、货币/掉落物/支线/NPC/机关/精英/商店库存状态，以及基地格子布局、科技、订单与矿石/金属等新资源。进入“我的队伍”可导出 JSON 备份或导入旧备份；导入前会验证基本结构，无效文件不会覆盖当前进度。清除网站数据或更换浏览器前请先导出备份。

## 目录

- `data/`、`schema/`：原创内容数据及 JSON Schema
- `src/battle/`、`capture/`、`base/`、`breeding/`、`progression/`、`quests/`、`build/`、`shop/`、`explore/`：独立于 Phaser 的核心规则（含基地布局/科技树/加工/订单）
- `src/world/`：地图生成、区域、遭遇与聚落 NPC 规则
- `src/player/`：个体、队伍与存档迁移
- `src/scenes/`：Phaser 游戏场景与懒加载导航
- `src/ui/`、`src/dex/`：共享按钮、滚动、无障碍反馈和图鉴筛选分页规则
- `tests/`：核心规则、长期循环与规模测试
- `scripts/validate-pals.mjs`、`scripts/browser-smoke.mjs`：数据校验与真实浏览器流程验收
- `PLAN.md`：完整阶段计划与验收标准
- `PROJECT_NOTES.md`：背景、数据字段和参考资料说明

## 内容约束

新增内容时只参考外部资料的字段结构，不复制具体名称、描述、数值或美术。修改数据结构时同步更新 TypeScript 类型、Schema、数据和校验脚本；完成一个独立功能后运行相关检查并创建中文说明的本地 Git 提交。
